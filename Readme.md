# Civic Connect

A modern community-driven civic issue reporting and tracking platform built with **HTML, CSS, and JavaScript**.

## Overview

Civic Connect enables citizens to report infrastructure issues such as potholes, water leakage, garbage overflow, drainage problems, and streetlight failures. The platform provides an intuitive interface to explore reported issues, visualize city-wide data, and encourage community participation.

## Features

* Responsive modern UI
* Interactive city issue map (Leaflet.js)
* Community issue categories
* Recent issue reports section
* Analytics dashboard
* LocalStorage-based data management
* Mobile-friendly design
* Clean component-based structure

## Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Leaflet.js
* Chart.js
* LocalStorage
